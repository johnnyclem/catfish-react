# ADR-003: Journal Commit = Discovery Contract

## Decision

Facts must be logged (drag-to-log) in the Journal to count toward deductions.

## Rationale

- Forces player engagement with discovered information
- Gives the Journal UI a meaningful purpose
- Creates a clear "discovery" vs "exposure" distinction

## Status

Locked. Core to the accusation/deduction mechanic.

## Implementation Status

Journal feature is stubbed (Pass 5). The drag-to-log interaction and
cross-reference linking are not yet built.
