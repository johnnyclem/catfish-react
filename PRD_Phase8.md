# Phase 8 — Eastworld Chat System (Full LLM Integration)

## Summary

Replace the stub chat client with real Eastworld LLM responses, add character-initiated messages, implement the full DM flow with date invitations, and build the messaging UI into a complete conversation system.

## Motivation

Chat currently uses `StubDateEastworldClient` which returns canned paraphrases. There's no character personality, no proactive messaging, and no narrative progression through DMs. The chat system is the primary investigation surface — players need to discover facts through conversations, receive date invitations, and feel like they're texting real people.

## Deliverables

### 8.1 Eastworld Chat Client
- Replace `StubDateEastworldClient` with real `EastworldVoiceService` integration
- Load character personality prompts from `Docs/date-mode/agents/*.md`
- Per-character system prompts with topic guardrails from `agent-guardrails.md`
- Session management: 3000 char budget per character, reset on new run
- Cache responses by FNV-1a hash (same input → same response within session)
- Network failure fallback: paraphrase + "(connection unstable)" indicator

### 8.2 Character-Initiated Messages
- `ContentScheduler` triggers character messages on day advance:
  - Day 2+: matched characters send follow-up messages
  - Day 3+: characters reference discovered facts ("did you see my post?")
  - Day 4+: characters send date invitations
  - Day 7: killer sends meet invitation (special handling)
- Messages stored as `ChatMessage` with `isFromPlayer: false`
- Notification badge on LotsOFish tab when unread messages exist

### 8.3 DM Content Authoring
Add scripted DM chains to `content.json`:
- Per-character opening messages (1-2 per character, triggered on match)
- Follow-up messages keyed to day number (2-3 per character per day)
- Reaction messages keyed to discovered facts (1-2 per major fact)
- Date invitation messages (1 per character, triggered day 3+)
- Day 7 meet invitation (per killer, different tone)
- Total: ~50-60 scripted messages

### 8.4 Date Invitation in Chat
- New `ChatMessage.kind`: `.dateInvitation` with location + sceneID
- Inline accept/decline buttons in chat bubble
- Accept → creates `scheduledDate` on `MatchRelationship`
- Decline → character reacts (affinity -1), can re-invite next day
- Post-date follow-up message (scripted) referencing date outcome

### 8.5 Chat UI Improvements
- Typing indicator before character responses (1-3s delay based on message length)
- Message timestamps
- Unread message indicator (blue dot)
- Character avatar in message bubbles
- Voice message playback (if voiceLineID exists on message)
- "View profile" button in chat header
- Chat scroll-to-bottom on new messages

### 8.6 Mail App — Notification Inbox
Replace `AppStubView` for `mail` with a notification inbox:
- System notifications: "You matched with Kai!", "New fact discovered"
- Date reminders: "Your date with River is tomorrow"
- Accusation deadline: "Day 7 — time's running out"
- Empty state: "No mail yet. Start swiping!"
- Notifications generated by `ContentScheduler` on day advance

## Acceptance Criteria

1. Chat responses are character-specific with correct personality
2. Characters send proactive messages on day advance
3. Date invitations work end-to-end in chat
4. Mail app shows game notifications
5. Topic guardrails prevent off-limits content
6. Session budget enforced (no infinite chat)
7. Build succeeds, all tests pass
